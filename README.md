# MiniCraft

Um mini jogo estilo Minecraft feito com HTML5 Canvas e JavaScript puro.

## Controles

- **Clique esquerdo**: coloca bloco selecionado
- **Clique direito**: remove bloco
- **Roda do mouse**: troca tipo de bloco
- **WASD**: move a câmera

## Como rodar

Abra o `index.html` no navegador.
